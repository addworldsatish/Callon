# PERFECT PRINTING HOUSE — Sales / Delivery Challan App

Version 1.1 — Android offline-first source project.

## Included
- No GST / tax fields
- Automatic challan numbering
- Customer name, mobile, address and remarks
- Multiple line items with quantity, rate and amount
- Automatic total calculation
- Save, edit, delete and search/history
- Local SQLite storage; works without an account or server
- A4 PDF generation
- Android share sheet (WhatsApp can be selected if installed)
- Android print framework support
- Company name, phone and address settings
- Receiver and authorized signature lines
- Portrait phone UI

## Application ID
`com.perfectprintinghouse.challan`

## Build
Open the project folder in Android Studio. Android Studio will need Android SDK and Gradle dependencies available at least once to build. Then use **Build > Build APK(s)**.

This package is source code, not a precompiled APK. The current execution environment does not contain the Android SDK/build toolchain needed to compile a genuine APK binary.
